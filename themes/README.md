# ธีมของนักเรียน (themes/)

ทุกคนในห้องทำธีมหน้าโปรไฟล์ของตัวเองด้วย CSS แล้วส่งเข้าเว็บผ่าน **Pull Request** ได้

## ทำยังไง (ไม่ต้องลง Git ก็ได้)

1. เข้าเว็บ → `/me` → แท็บ **ธีม** → กด **สร้างธีมของฉันบน GitHub**
   (ระบบเปิดหน้า GitHub พร้อมไฟล์ตัวอย่าง `themes/<เลขที่ของคุณ>/theme.css` ให้แล้ว)
2. แก้ CSS ตามใจ → กด **Commit changes… → Propose changes → Create pull request**
3. รอระบบตรวจอัตโนมัติ (ต้องขึ้นเครื่องหมายถูกสีเขียว) แล้วรอผู้ดูแลกด merge
4. หลัง merge เว็บอัปเดตเอง ธีมจะเปิดใช้บนโปรไฟล์ของคุณ (ปิด/เปิดได้ที่ `/me` → ธีม)

ถ้าใช้ Git เอง: คัดลอก `themes/_template` เป็น `themes/<เลขที่ของคุณ>` แล้วเปิด PR ตามปกติ
ลองดูผลในเครื่อง: `npm run dev` แล้วเปิดโปรไฟล์ของตัวเอง

## โครงสร้าง

```
themes/12/
  theme.css    จำเป็น
  theme.json   ไม่บังคับ  { "name", "tagline", "author" }
  bg.png       ไม่บังคับ  รูปที่ theme.css เรียกด้วย url("./bg.png")
```

## กติกา (ระบบตรวจให้อัตโนมัติ)

- PR หนึ่งอันแก้ได้แค่โฟลเดอร์ `themes/<เลขที่>/` ของตัวเองโฟลเดอร์เดียว
- เขียน CSS ปกติ ระบบจะครอบให้มีผลกับโปรไฟล์ของคุณเท่านั้น (`:root` = ตัวหน้าโปรไฟล์)
- ห้าม: `@import`, `@font-face`, `url()` ที่ชี้ไปเว็บอื่น, `position: fixed/sticky`, `z-index` เกิน 50, CSS nesting
- ใช้ได้: `@media`, `@supports`, `@keyframes` (ชื่อต้องขึ้นต้น `t<เลขที่>-`)
- `theme.css` ไม่เกิน 60KB, รูปแต่ละไฟล์ไม่เกิน 300KB (png/jpg/webp/gif/svg/avif)
- ธีมต้องไม่บังปุ่มสำคัญ ไม่ทำให้อ่านข้อความไม่ได้ และไม่มีเนื้อหาที่ไม่เหมาะสม ผู้ดูแลอาจขอให้แก้ก่อน merge

## ตรวจเองก่อนส่ง

```
node scripts/check-themes.ts
```
